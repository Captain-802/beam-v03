Beam Design Editing Guide

Use this table to decide which small file to send or edit. Keep index.html as the app shell and change logic in the matching JavaScript file.

Scope (19 Sep 2026): the tool handles one span, End 1 (x = 0) to End 2 (x = L), with seven restrained / free flags per end (Ux, Uy, Uz, Rx, Ry, Rz, warping) held in S.ends; there is no support list, no intermediate support, overhang or pattern loading anywhere in the code, so do not add one to a single file — every engine reads the end flags (AUDIT.md “19 Sep 2026 single-span scope, end-condition DOFs”). House rules for every edit: single-file deployable, no external dependency, no inline handler or eval, mm-N units inside the engine, pure check functions, every check prints clause + formula + values + utilisation + status, no invented coefficient without a [verify] tag; after editing run node --test tests/*.test.cjs, node tests/batch/run-batch.cjs, pwsh ./build-single-html.ps1 and the parity test (README “How to run”).

Eurocode 3 Engine Notes

The EC3 design is split into two layers. Clause 6.2 cross-section resistance lives in js/checks/eurocode-checks.js. The EC3 unrestrained beam Mcr / lateral-torsional buckling override lives in js/08-mcr-eigen-patch.js.

Cross-Section Resistance (EN 1993-1-1, Clause 6.2)

  • High shear reduction: the engine checks the 0.5Vpl,Rd threshold from Clause 6.2.8. If shear exceeds this, it reduces bending resistance using ρ = (2VEd/Vpl,Rd - 1)2 on the web shear area.
  • Coexistent shear and moment: for I-sections, the engine checks shear and moment together along the span, rather than only checking shear at the point of maximum moment. If VEd > Vpl,Rd, the reduced moment formula is bypassed because the section has already failed in pure shear.
  • Axial and bending interaction: for Class 1 and Class 2 sections, it applies the Clause 6.2.9 plastic interaction waivers, including the low axial-force cases where no bending reduction is required.
  • Member buckling display: Clause 6.3.3 Annex B member buckling is only calculated and displayed when NEd is compressive. For a pure beam with NEd = 0, the governing strength check remains the Clause 6.2 cross-section resistance, so the redundant Annex B interaction rows are suppressed.
  • Serviceability validation: an enabled SLS combination must produce a real load effect from the active loads. If every enabled SLS combination has zero factors for the load cases present, the calculator reports No SLS loads applied instead of showing a misleading 0.0 mm deflection at a support.
  • Class limits: a Class-4 web in uniform compression is evaluated with Aeff (EN 1993-1-5 4.4) in Nc,Rd, Nb,Rd and the Table 6.7 Class-4 column; Class 4 under the combined N + M stress gradient and Class-4 flanges are still blocked for PASS (NOT VERIFIED with the reason printed).

Areas for Improvement / Limitations

Shear buckling: the engine checks whether the web is susceptible to shear buckling using the EN 1993-1-1 Clause 6.2.6(6) limit, hw/tw > 72ε/η. If shear buckling is required, the calculator blocks PASS and reports the check as unsupported. This is safe, but it limits use for deep unstiffened webs and plate-girder type members, where EN 1993-1-5 shear buckling design would be required.

Biaxial bending: the applied Mz is one constant design value (no horizontal load component, so no Mz(x) diagram). It enters the 6.2.9 biaxial interaction, the cl 6.2.10 M-V-N sweep, the Annex B 6.61 / 6.62 terms and the I/H flange classification; torsion combined with an imposed Mz or with NEd is still blocked for PASS.

Torsion (SCI P385 and EN 1993-6)

  • Elastic warping analysis: for open sections, the engine implements SCI P385 Method B using the P385 torsional properties. It evaluates rotation φ, warping moment Mw, induced minor-axis moment Mz, and major-axis moment My at stations along the span, then uses the governing coincident combination for the cross-section check.
  • Yield interaction: open-section bending plus torsion is checked using the SCI P385 Section 3.1.2 interaction. In the EC3 unrestrained path, the same effects feed the BS EN 1993-6 Annex A bending-torsion interaction with kα amplification.
  • Class-consistent stresses: the code uses plastic resistances for Class 1/2 sections and elastic resistances for Class 3 sections under combined torsion. This avoids the unconservative Class 3 result that can occur if plastic flange/minor-axis resistances are used, and matches the validation note against the independent commercial-software warping-torsion example.

Closed Sections and LTB

SHS and RHS members are treated as closed hollow sections for major-axis beam bending. EN 1993-1-1 Clause 6.3.2.1(2) says these sections are not susceptible to lateral-torsional buckling, so the FEM Mcr eigensolver is skipped and Mb,Rd = Mc,Rd is reported directly.
