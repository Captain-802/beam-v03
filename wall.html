Beam in Wall — Eurocode 3 / BS 5950

Beam-in-wall front end of the Steel Beam Designer (20 Sep 2026): the cavity-wall model below (leaves, cavity, recess, placement, load ledgers per leaf) generates the load list of the unchanged beam-v03 engine, which then solves one single-span beam with any end condition (six degrees of freedom plus warping at each end: simply supported, fixed, propped, cantilever, guided / sliding end, laterally clamped, or any custom combination) and internal hinges under arbitrary loads by the direct stiffness method, then performs the EN 1993-1-1 (UK NA) or BS 5950-1:2000 member checks for PFC channels, SHS (hot-finished or cold-formed), RHS (hot-finished), UB universal beams, or UC universal columns. Blue Book section data is built in; every value is editable.

Design code
Switching code changes the cross-section/member-resistance formulas (classification, shear, moment, LTB, buckling). The beam analysis, loads, and combinations are shared.

Geometry & end conditions
One span from End 1 (x = 0) to End 2 (x = L). Each end has six degrees of freedom plus warping, each restrained (ticked) or free: Ux axial, Uy lateral, Uz vertical, Rx twist, Ry rotation about the major axis (in-plane fixity), Rz rotation about the minor axis (lateral bending), warping φ′ = 0. Uz + Ry = fixed, Uz alone = pinned, Ry alone = guided (sliding end: rotation held, vertical free, no vertical reaction), neither = free end. Uy, Rz, Rx and warping are the LTB eigen and torsion boundary conditions (Uy + Rx = fork end, + Rz = laterally clamped); Ux is the axial load path (NEd needs it at one end at least). A cantilever is End 1 fully restrained and End 2 free — the root must be End 1 (x = 0): a cantilever rooted at End 2 (End 2 Uz + Ry, End 1 free) is refused with “mirror the member”, so enter the loads from the root; the guided-fixed preset holds End 1 fixed and End 2 sliding. The strut effective lengths default from these fixities (P360 Table 6.2 / BS 5950 Table 22 style, printed [verify]). Changing a box switches the drop-list to Custom; a mechanism is refused with a message naming the missing restraint. An end that lifts in any combination (negative reaction) blocks PASS with a “Hold-down required” message unless hold-down provided is ticked for it, in which case the design hold-down force is printed as an advisory; uplift is also tested with the γG,inf companions (G at 1.0, STR set B, and 0.9, EQU set A) of every ULS combination. Web transverse forces (EC3, EN 1993-1-5 clause 6): each end reaction is checked as a patch load on the bottom flange with the entered stiff bearing length ss along the member (blank = the lower bound 0: a station that passes at ss = 0 is verified for any seating, one that fails at 0 is NOT VERIFIED until the seating length is entered; capped at hw); an end reaction is load type (c). Tick bearing stiffener provided to declare a stiffener at that end instead — the stiffener itself must then be designed to EN 1993-1-5 9.4.
Internal hinges (moment releases)
An internal hinge releases the in-plane bending moment (M = 0) at that point inside the span — the moment diagram, deflection and elastic critical moment Mcr all redistribute. The ends must keep the member stable with the hinge (e.g. a fixed-pinned span with one hinge); a mechanism is refused. Lateral and torsional continuity are kept across the hinge; if the physical connection also releases warping or is braced, add that separately in the LTB restraint options.

Loads
Forces positive downward (kN, kN/m). Moment positive anticlockwise (kN m). Enter characteristic (unfactored) values and tag each load's case the partial factors come from the Load Combinations below, not from the load itself. Section self-weight is added automatically as Dead (G) from the selected section mass/m. Point loads (EC3): each is also checked as a transverse force on the web (EN 1993-1-5 clause 6, with the 7.2 interaction) using its own stiff bearing length ss (blank = 0 mm); tick bearing stiffener provided where a stiffener will be designed (EN 1993-1-5 9.4). A load directly over an end holding Uz is treated as transferred through the web (type b).
When activated, each load row gains its own shear-centre offset e (mm). In EC3 unrestrained mode each transverse load also gets its own zg load height above the shear centre. Applied moments act through the shear centre. Automatic self-weight acts through the centroid: e = 0 for doubly symmetric sections, but e = esc for PFC channels. Open-section torsion (EC3): twist is prevented at every end whose Rx box is ticked (at least one end must hold it); with Uy + Rx at both ends and warping free at both, full-span or point torques use the SCI P385 Appendix C closed forms, any other layout (torsion cantilever with Rx at one end only, partial-span eccentric load, warping-fixed end) the warping-torsion finite-element model, which reports its mesh error. Tick warping under End conditions only where the connection really prevents warping of the flanges; the default is a fork end with free warping.
Load Combinations
Defaults: ULS 1.35G + 1.5Q (Eq 6.10) and SLS 1.0G + 1.0Q (total deflection); for the NA 2.23 variable-actions-only deflection criterion set G = 0 in the SLS combination. Switch on every combination you want considered in the design. For each ULS combination switched on, the solver finds Shear/Moment everywhere along the member; the worst case from any switched-on combination governs each check (envelope), and the report states which combination governs which check. At least one ULS and one SLS (deflection) combination must be on. Every ULS combination with γG > 1.0 is supplemented automatically by its γG,inf companions (G at 1.0, STR set B, and 0.9, EQU set A, variable factors as entered) solved for the end reactions only (uplift / hold-down and web bearing); the moment and shear envelopes keep the entered factors.
Axial & lateral-torsional buckling
Fully restrained: the compression flange is held in position along its length (e.g. by a slab or decking), so lateral–torsional buckling cannot occur and the design follows the SCI restrained-beam procedure to EN 1993-1-1 (classification → shear → shear buckling → moment → deflection). Applies to the EC3 code path.
Standard = closed-form Mcr = C1(π²EIz/LE²)√[Iw/Iz + LE²GIt/(π²EIz)] with C1 from the NCCI SN003a tables (simply supported or fixed-ended full-span UDL / central point load, recognised from the load list) or the end-moment formula (ψ = M1/M2), the Serna quarter-point expression for a general diagram, C2·zg where published (a destabilising zg on any other diagram blocks PASS unless the destabilising LE switch carries it), NCCI SN006a for cantilevers and the P385/P362 channel chain — as MasterSeries-type software does; LE = LE-factor × L over the whole member; Mb,Rd from the Mcr chain (the P362 simplified slenderness is printed for comparison only). Eigen = finite-element eigenvalue of the actual moment diagram with each load’s height, the end degree-of-freedom flags (Uy, Rz, Rx, warping), the intermediate lateral restraints (bay by bay between them) and internal hinges. The report prints both values and their ratio.
Positive = compression, negative = tension. Entered directly as the governing ULS design value it is not run through the Load Combinations below. Leave 0 for a pure beam.

Blank = the strut buckling lengths Lcr,y and Lcr,z come from the end fixities under End conditions (y-y from Uz / Ry, z-z from Uy / Rz: 0.7 L held in position and direction at both ends, 0.85 L direction at one end, 1.0 L direction at neither, 2.0 L cantilever, 1.2 L fixed with a guided far end; P360 Table 6.2 / BS 5950 Table 22 style, printed [verify]); the minor axis is shortened to the lateral-restraint spacing where restraints are modelled. A number here overrides both axes (an entered 1.0 is an override). LTB effective length: on the EC3 standard (closed-form) route LE = factor × L (blank = 1.0) with fork ends (Uy + Rx) required at both ends — an end that releases Uy or Rx is NOT VERIFIED on that route (use the FE eigenvalue method, which models the end flags), a laterally clamped or warping-fixed end is taken as a fork (conservative). On the BS 5950 path a blank factor takes LE from the end flags: Table 13 for fork ends at both ends (1.0 L, or 0.7 L with Rz held at both ends; 1.2 L / 0.85 L destabilising), Table 14 (d) for a cantilever whose root holds Uy, Rz and Rx (tip free 0.8 L / 1.4 L destabilising, tip Rx 0.6 L, tip Uy + Rx 0.5 L), printed [verify]; any other end flag set has no tabulated row and is NOT VERIFIED until a factor is entered here.
PFC under axial compression: torsional and torsional-flexural buckling (EN 1993-1-1 cl 6.3.1.4) are checked with Ncr,T = (GIT + π²EIw/LT²)/i0² and the torsional-flexural coupling with the major-axis flexural mode through the shear-centre offset esc (SCI P385 Table A.3). LT is the length between points where twist is prevented; blank takes the largest spacing of the twist restraints (the ends with Rx ticked and the intermediate restraints with φ held, capped at Lcr,y) — a lateral-only restraint shortens Lcr,z but not LT.
For PFC, this sets both the LTB effective length (Table 13/14) and the strut effective length. For SHS, LTB does not apply (cl 4.3.6.1), so this sets only the strut effective length (Table 22).
C1 (moment-gradient factor for LTB) is computed from the official end-moment-gradient table where that case applies. For transverse-load or combined cases, the safe default C1=1.0 is used unless you override it with a verified value (e.g. from LTBeam or other software).
