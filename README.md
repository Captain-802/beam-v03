**Scope (19 Sep 2026, owner's decision):** ONE span from End 1 (x = 0) to End 2 (x = L); no intermediate supports, overhangs, multi-span logic or automatic pattern loading (removed, not hidden &mdash; AUDIT.md "19 Sep 2026 scope change"). Each end carries seven flags, each **restrained or free**: U<sub>x</sub> (axial translation), U<sub>y</sub> (lateral translation), U<sub>z</sub> (vertical translation), R<sub>x</sub> (twist), R<sub>y</sub> (rotation about the major axis, in-plane), R<sub>z</sub> (rotation about the minor axis, lateral bending) and warping (&phi;&prime; = 0). The *Geometry &amp; end conditions* panel of `index.html` offers a preset drop-list (Simply supported, Fixed-fixed, Fixed-pinned (propped cantilever), Cantilever, Guided-fixed, Pinned-guided, Custom), four quick buttons, and two columns "End 1 (x = 0)" / "End 2 (x = L)" with the seven boxes, a glyph of the end condition, and &mdash; for an end holding U<sub>z</sub> &mdash; the hold-down box, the stiff bearing length s<sub>s</sub> and the bearing-stiffener box; ticking any box switches the drop-list to Custom (`applyEndPreset()`, `setEndDof()`, `endPresetSelection()`, `endsPanelHtml()`, `endGlyphSvg()` in `js/03-state-ui.js`, all pure apart from the DOM binding in `renderEndsPanel()`). Mapping: U<sub>z</sub> + R<sub>y</sub> = fixed, U<sub>z</sub> alone = pinned, R<sub>y</sub> alone = guided (sliding end: rotation held, vertical free, no vertical reaction), neither = free end (in-plane solver); U<sub>y</sub> / R<sub>z</sub> / R<sub>x</sub> / warping = the LTB eigen (v, v&prime;, &phi;, &phi;&prime;) and torsion FE (&phi;, &phi;&prime;) boundary conditions; U<sub>x</sub> = the axial load path (N<sub>Ed</sub> needs it at one end at least). A cantilever is End 1 fully restrained (warping included) and End 2 free. Internal hinges stay (in-plane moment release at x, lateral / twist continuity kept). The strut effective lengths default from the end fixities (P360 Table 6.2 / BS 5950 Table 22 style, printed with their basis and [verify], overridable by the L<sub>E</sub>/L input); a mechanism is refused with a message naming the missing restraint. The lateral flags also drive the LTB routes (19 Sep 2026 review fixes, AUDIT.md "19 Sep 2026 review fixes: end conditions of the closed-form routes"): the EC3 standard (closed-form) M<sub>cr</sub> route needs fork ends (U<sub>y</sub> + R<sub>x</sub>) at both ends or the SN006a cantilever (root U<sub>y</sub> + R<sub>z</sub> + R<sub>x</sub>, free tip; `isSn006aCantilever()`) and is NOT VERIFIED otherwise (the FE eigen route models any flag set); the BS 5950 path validates the same mechanisms and takes L<sub>E</sub> from BS 5950 Table 13 / Table 14 (d) by the flags when the factor is blank (`bs5950LtbLength()`, printed [verify]), blocking end sets without a tabulated row. The brief and the report open with an "End conditions" line (the flags of each end, the derived in-plane and LTB end types, the preset name, the hinges) and the Member Forces table carries the End 1 / End 2 reactions (R and M as the end type carries them, "guided: M only", "free: none").

**Features (EC3 path, EN 1993-1-1 + UK NA; BS 5950-1 path separate):** rolled UB / UC / PFC / SHS / RHS with the P363 and P385 tables; one span with any end condition (the seven flags per end: simply supported, fixed, propped, cantilever, guided / sliding end, laterally clamped or warping-restrained ends, or any custom combination) and internal hinges; **Elastic critical moment M<sub>cr</sub> (EC3, not fully restrained):** the `M<sub>cr</sub> method` select under *Axial & lateral-torsional buckling* sets `S.mcrMethod` to `eigen` (default) or `standard`. `eigen` solves M<sub>cr</sub> by the finite-element eigenvalue method in `js/08-mcr-eigen-patch.js` for the actual moment diagram, per-load heights z<sub>g</sub>, the end DOF flags (v from U<sub>y</sub>, v&prime; from R<sub>z</sub>, &phi; from R<sub>x</sub>, &phi;&prime; from warping), intermediate lateral restraints and internal hinges (bay by bay between lateral restraints). `standard` delegates to the closed-form implementation `checksEC3UnrestrainedSCI()` in `js/checks/eurocode-checks.js` (kept alive by the patch as `window.checksEC3UnrestrainedStandard`): C<sub>1</sub> from the NCCI SN003a Table 3.2 rows recognised from the load list of the governing combination (simply supported or fixed-ended full-span UDL / central point load: 1.127/0.454, 1.348/0.630, 2.578/1.554, 1.683/1.645), the SCI end-moment curve when only couples act ("Not Loaded", self-weight allowed) or the diagram is linear, or the Serna quarter-point expression for a general diagram (C<sub>2</sub> unpublished); M<sub>cr</sub> = C<sub>1</sub>(&pi;&sup2;EI<sub>z</sub>/L<sub>E</sub>&sup2;){&radic;[I<sub>w</sub>/I<sub>z</sub> + L<sub>E</sub>&sup2;GI<sub>t</sub>/(&pi;&sup2;EI<sub>z</sub>) + (C<sub>2</sub>z<sub>g</sub>)&sup2;] &minus; C<sub>2</sub>z<sub>g</sub>} with G = 81000 N/mm&sup2;, NCCI SN006a for I/H cantilevers, the same chain with I<sub>w</sub> = 0 for hollow sections (&chi;<sub>LT</sub> curve from one shared `ltbCurveNA()`, NA Table NA.1, on both routes) and the P385/P362 channel &kappa; chain, with L<sub>E</sub> = L<sub>E</sub>-factor &times; L over the whole member - the route MasterSeries-type software prints; the eigensolver is not run. **Design basis** of the standard route is the M<sub>cr</sub> chain (`ltb.MbRd = ltb.MbMcr` = &chi;<sub>LT,mod</sub>W<sub>y</sub>f<sub>y</sub>/&gamma;<sub>M1</sub> &le; M<sub>c,Rd</sub>, also handed to the Eq 6.61/6.62 interaction); the P362 Expn 6.55 simplified slenderness (`ltb.MbSimp`) is printed for comparison only. **Load height** on the standard route is one z<sub>g</sub> per combination, `stdZgFor()`: the most destabilising signed per-load value among the loads active in the combination (an upward load at +z<sub>g</sub> is stabilising, so its sign is reversed; default `S.za` when no per-load value exists); it is always printed (`ltb.zgNote`), applied only where SN003a publishes C<sub>2</sub>, and a destabilising z<sub>g</sub> on any other diagram pushes a blocking message (`ltb.zgBlocked`) unless the destabilising &times;1.2 L<sub>E</sub> switch carries it (advisory; a further advisory when both treatments overlap). Both routes expose `ltb.McrStandard`, `ltb.McrEigen` (null in standard mode) and the MasterSeries-style C<sub>1</sub> inputs `ltb.c1in = {M1, M2, Mo, psi, mu}` (segment end moments, M<sub>2</sub> the larger; mid-segment moment above the chord; &psi; = M<sub>1</sub>/M<sub>2</sub>; &mu; = M<sub>o</sub>/M<sub>2</sub> capped at 300); in eigen mode the comparison (`mcrStandardFor(a, sec, seg, {fb, factors})`) describes the LTB-governing combination's own diagram, loads and z<sub>g</sub>, and the report names the method in its heading, prints the `C1 = fn(M1, M2, Mo, psi, mu)` line in standard mode and the ratio M<sub>cr,eigen</sub>/M<sub>cr,standard</sub> in eigen mode.
