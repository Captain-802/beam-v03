# Beam Design Modular Source

Single-file, zero-dependency EC3 / BS 5950 steel beam checker (rolled UB / UC / PFC / SHS / RHS) for one span with any end condition, deployed through GitHub Pages into the CED Google Sites page.

The September 2026 structural audit, corrections, reference basis and remaining limitations are documented in [AUDIT.md](AUDIT.md). The state of branch `ms-brief-standard-mcr` (what changed, EC3 trigger coverage before / after, the brief against the MasterSeries printout, the verification campaigns with their hand checks and the eigen-vs-closed-form M<sub>cr</sub> findings, known limitations, how to run everything; section 7 for the single-span scope) is summarised for the owning engineer in [docs/VERIFICATION_REPORT.md](docs/VERIFICATION_REPORT.md), and the branch is summarised for the pull request in [docs/RELEASE_NOTES.md](docs/RELEASE_NOTES.md).
The section tables (UB, UC, SHS, RHS completed from the MasterSeries 2025 UK library, cross-check and derivation basis) are documented in [docs/SECTION_LIBRARY.md](docs/SECTION_LIBRARY.md).

**Scope (19 Sep 2026, owner's decision):** ONE span from End 1 (x = 0) to End 2 (x = L); no intermediate supports, overhangs, multi-span logic or automatic pattern loading (removed, not hidden &mdash; AUDIT.md "19 Sep 2026 scope change"). Each end carries seven flags, each **restrained or free**: U<sub>x</sub> (axial translation), U<sub>y</sub> (lateral translation), U<sub>z</sub> (vertical translation), R<sub>x</sub> (twist), R<sub>y</sub> (rotation about the major axis, in-plane), R<sub>z</sub> (rotation about the minor axis, lateral bending) and warping (&phi;&prime; = 0). The *Geometry &amp; end conditions* panel of `index.html` offers a preset drop-list (Simply supported, Fixed-fixed, Fixed-pinned (propped cantilever), Cantilever, Guided-fixed, Pinned-guided, Custom), four quick buttons, and two columns "End 1 (x = 0)" / "End 2 (x = L)" with the seven boxes, a glyph of the end condition, and &mdash; for an end holding U<sub>z</sub> &mdash; the hold-down box, the stiff bearing length s<sub>s</sub> and the bearing-stiffener box; ticking any box switches the drop-list to Custom (`applyEndPreset()`, `setEndDof()`, `endPresetSelection()`, `endsPanelHtml()`, `endGlyphSvg()` in `js/03-state-ui.js`, all pure apart from the DOM binding in `renderEndsPanel()`). Mapping: U<sub>z</sub> + R<sub>y</sub> = fixed, U<sub>z</sub> alone = pinned, R<sub>y</sub> alone = guided (sliding end: rotation held, vertical free, no vertical reaction), neither = free end (in-plane solver); U<sub>y</sub> / R<sub>z</sub> / R<sub>x</sub> / warping = the LTB eigen (v, v&prime;, &phi;, &phi;&prime;) and torsion FE (&phi;, &phi;&prime;) boundary conditions; U<sub>x</sub> = the axial load path (N<sub>Ed</sub> needs it at one end at least). A cantilever is End 1 fully restrained (warping included) and End 2 free. Internal hinges stay (in-plane moment release at x, lateral / twist continuity kept). The strut effective lengths default from the end fixities (P360 Table 6.2 / BS 5950 Table 22 style, printed with their basis and [verify], overridable by the L<sub>E</sub>/L input); a mechanism is refused with a message naming the missing restraint. The lateral flags also drive the LTB routes (19 Sep 2026 review fixes, AUDIT.md "19 Sep 2026 review fixes: end conditions of the closed-form routes"): the EC3 standard (closed-form) M<sub>cr</sub> route needs fork ends (U<sub>y</sub> + R<sub>x</sub>) at both ends or the SN006a cantilever (root U<sub>y</sub> + R<sub>z</sub> + R<sub>x</sub>, free tip; `isSn006aCantilever()`) and is NOT VERIFIED otherwise (the FE eigen route models any flag set); the BS 5950 path validates the same mechanisms and takes L<sub>E</sub> from BS 5950 Table 13 / Table 14 (d) by the flags when the factor is blank (`bs5950LtbLength()`, printed [verify]), blocking end sets without a tabulated row. The brief and the report open with an "End conditions" line (the flags of each end, the derived in-plane and LTB end types, the preset name, the hinges) and the Member Forces table carries the End 1 / End 2 reactions (R and M as the end type carries them, "guided: M only", "free: none").

## Features (final list, single-span scope)

EC3 path (EN 1993-1-1 + UK NA); the BS 5950-1 path is separate and lighter (see the last bullet).

- **Sections:** rolled UB / UC / PFC / SHS / RHS from the P363 / P385 tables, completed from the MasterSeries 2025 UK library ([docs/SECTION_LIBRARY.md](docs/SECTION_LIBRARY.md)); hot-finished and cold-formed hollow sections (`shsType`, `rhsType`) with their own strut curves and flat widths; S275 / S355 / S460 by thickness.
- **Member:** one span, End 1 (x = 0) to End 2 (x = L), seven flags per end (U<sub>x</sub>, U<sub>y</sub>, U<sub>z</sub>, R<sub>x</sub>, R<sub>y</sub>, R<sub>z</sub>, warping) with six presets (simply supported, fixed-fixed, fixed-pinned, cantilever, guided-fixed, pinned-guided) or any custom set; internal hinges; intermediate lateral restraints (v, v&prime;, &phi;, &phi;&prime;); every mechanism refused with a message naming the missing restraint.
- **Loads and combinations:** point, UDL, trapezoidal and moment loads by case (G / Q / W / E) with eccentricity e (torque) and load height z<sub>g</sub> per load; user ULS / SLS combinations; &gamma;<sub>G,inf</sub> companions (1.0 STR set B, 0.9 EQU set A) for the end reactions; uplift / hold-down at either end; constant N<sub>Ed</sub> (compression or tension) and M<sub>z</sub>.
- **Classification and cross-section resistance:** class under the actual stress distribution (I/H flange outstands under M<sub>y</sub> + M<sub>z</sub> + N, web under N), A<sub>eff</sub> of a Class-4 web in uniform compression; bending, shear, high-shear M<sub>v,Rd</sub> for every family, M-N and biaxial 6.2.9, M-V-N 6.2.10, net-section tension; web transverse forces at every point load and end reaction (EN 1993-1-5 clause 6 with the 7.2 interaction, stiff bearing length and declared stiffeners).
- **Member stability:** flexural buckling with the strut lengths from the end fixities (0.7 / 0.85 / 1.0 / 2.0 / 1.2 L, printed [verify], overridable); PFC torsional / torsional-flexural buckling; Annex B interaction 6.61 / 6.62 (Table B.1 / B.2, RHS row, Table 6.7 Class-4 column); lateral-torsional buckling by the FE eigenvalue M<sub>cr</sub> (default: real moment diagram, per-load z<sub>g</sub>, end DOFs, intermediate restraints, hinges, bay by bay) or by the standard closed-form chain (SN003a C<sub>1</sub> / C<sub>2</sub>, SCI end-moment curve, Serna, SN006a cantilevers, channel &kappa; chain; fork ends required, else NOT VERIFIED) with the 6.3.2.3 &chi;<sub>LT,mod</sub> (k<sub>c</sub> &ge; 0.60) on both routes; restraint design forces (advisory).
- **Torsion:** open sections by the P385 closed forms (fork ends, warping free) or the general warping-torsion FE (torsion cantilevers, partial-span torques, warping-fixed ends) with the P385 3.1.2 cross-section check, V<sub>pl,T,Rd</sub> and the EN 1993-6 Annex A LTB + torsion interaction; box-section torsion (St Venant).
- **Serviceability:** deflection span/n between two vertically held ends, L/180 [verify] for a vertically free end, optional absolute cap; twist advisory.
- **Output:** a three-state verdict (PASS / FAIL / NOT VERIFIED with the reason printed; unimplemented interactions block PASS instead of being ignored - the list is in [docs/VERIFICATION_REPORT.md](docs/VERIFICATION_REPORT.md) section 2.4); a MasterSeries-format design brief (the whole EC3 report since 20 Sep 2026) opening with the End conditions line and the per-end reactions; every check prints clause, formula, substituted values, utilisation and status; no invented coefficients (interpretations carry [verify]).
- **BS 5950-1 path:** classification, shear, bending, axial, strut and LTB (L<sub>E</sub> from Table 13 / 14 by the end flags when the factor is blank, printed [verify]), uplift, the same mechanism validation; web bearing / buckling advisory only; no torsion; any M<sub>z</sub> blocks.
- **Engineering:** single-file deployable (`dist/beam-design-single.html`), zero external dependencies, CSP-safe (no eval, no inline handlers), mm-N internal units, pure check functions, headless test harness (`tests/harness.cjs`) and a 279-case batch campaign with independent closed-form cross-checks and 59 hand checks.

## How to run

From the repository root (Node 22+; the campaign figures were produced on v24.14.1):

```text
node --test tests/*.test.cjs            # regression suite: 169 tests, ~20 s, includes the dist parity test
node --test tests/wall/*.test.cjs       # Beam in Wall page (wall.html): 23 tests
node tests/batch/run-batch.cjs          # single-span campaign: 279 cases / 479 runs, ~70 s; rewrites tests/batch/results.json and results.md
node tests/batch/run-batch.cjs PFC CUS  # subset: ids containing any of the substrings
node tests/batch/hand-checks.cjs        # the 59 hand-check comparisons step by step; exit 1 above 1 % (two explained method differences excepted)
pwsh ./build-single-html.ps1            # regenerates dist/beam-design-single.html from index.html + css + js
pwsh ./build-wall-single.ps1            # regenerates dist/beam-in-wall-single.html from wall.html + both css + js incl. js/wall
```

Before every commit: the suite green, the batch with `ERROR 0` (FAIL verdicts and cross-check mismatches are findings to read, not gate failures), the build run and the parity test (`tests/artifact.test.cjs`) green - the single-file distribution must match the modular source byte for byte. Expected batch counts at the end of the branch: PASS 349 / FAIL 82 / NOT VERIFIED 34 / ERROR 0, 14 invalid layouts thrown as declared, 0 cross-check mismatches. To open the tool: `index.html` (modular, needs the `css/` and `js/` folders beside it) or `dist/beam-design-single.html` (one file); `serve-dev.py` serves the folder locally. To reproduce a case in Node without the browser: `const {app} = require('./tests/harness.cjs'); const c = app(); c.reset(overrides); c.run('analyse()')` then `checks(a)`; the batch case objects in `tests/batch/cases.cjs` are ready-made overrides.

## Detailed notes by feature

**Elastic critical moment M<sub>cr</sub> (EC3, not fully restrained):** the `M<sub>cr</sub> method` select under *Axial & lateral-torsional buckling* sets `S.mcrMethod` to `eigen` (default) or `standard`. `eigen` solves M<sub>cr</sub> by the finite-element eigenvalue method in `js/08-mcr-eigen-patch.js` for the actual moment diagram, per-load heights z<sub>g</sub>, the end DOF flags (v from U<sub>y</sub>, v&prime; from R<sub>z</sub>, &phi; from R<sub>x</sub>, &phi;&prime; from warping), intermediate lateral restraints and internal hinges (bay by bay between lateral restraints). `standard` delegates to the closed-form implementation `checksEC3UnrestrainedSCI()` in `js/checks/eurocode-checks.js` (kept alive by the patch as `window.checksEC3UnrestrainedStandard`): C<sub>1</sub> from the NCCI SN003a Table 3.2 rows recognised from the load list of the governing combination (simply supported or fixed-ended full-span UDL / central point load: 1.127/0.454, 1.348/0.630, 2.578/1.554, 1.683/1.645), the SCI end-moment curve when only couples act ("Not Loaded", self-weight allowed) or the diagram is linear, or the Serna quarter-point expression for a general diagram (C<sub>2</sub> unpublished); M<sub>cr</sub> = C<sub>1</sub>(&pi;&sup2;EI<sub>z</sub>/L<sub>E</sub>&sup2;){&radic;[I<sub>w</sub>/I<sub>z</sub> + L<sub>E</sub>&sup2;GI<sub>t</sub>/(&pi;&sup2;EI<sub>z</sub>) + (C<sub>2</sub>z<sub>g</sub>)&sup2;] &minus; C<sub>2</sub>z<sub>g</sub>} with G = 81000 N/mm&sup2;, NCCI SN006a for I/H cantilevers, the same chain with I<sub>w</sub> = 0 for hollow sections (&chi;<sub>LT</sub> curve from one shared `ltbCurveNA()`, NA Table NA.1, on both routes) and the P385/P362 channel &kappa; chain, with L<sub>E</sub> = L<sub>E</sub>-factor &times; L over the whole member - the route MasterSeries-type software prints; the eigensolver is not run. **Design basis** of the standard route is the M<sub>cr</sub> chain (`ltb.MbRd = ltb.MbMcr` = &chi;<sub>LT,mod</sub>W<sub>y</sub>f<sub>y</sub>/&gamma;<sub>M1</sub> &le; M<sub>c,Rd</sub>, also handed to the Eq 6.61/6.62 interaction); the P362 Expn 6.55 simplified slenderness (`ltb.MbSimp`) is printed for comparison only. **Load height** on the standard route is one z<sub>g</sub> per combination, `stdZgFor()`: the most destabilising signed per-load value among the loads active in the combination (an upward load at +z<sub>g</sub> is stabilising, so its sign is reversed; default `S.za` when no per-load value exists); it is always printed (`ltb.zgNote`), applied only where SN003a publishes C<sub>2</sub>, and a destabilising z<sub>g</sub> on any other diagram pushes a blocking message (`ltb.zgBlocked`) unless the destabilising &times;1.2 L<sub>E</sub> switch carries it (advisory; a further advisory when both treatments overlap). Both routes expose `ltb.McrStandard`, `ltb.McrEigen` (null in standard mode) and the MasterSeries-style C<sub>1</sub> inputs `ltb.c1in = {M1, M2, Mo, psi, mu}` (segment end moments, M<sub>2</sub> the larger; mid-segment moment above the chord; &psi; = M<sub>1</sub>/M<sub>2</sub>; &mu; = M<sub>o</sub>/M<sub>2</sub> capped at 300); in eigen mode the comparison (`mcrStandardFor(a, sec, seg, {fb, factors})`) describes the LTB-governing combination's own diagram, loads and z<sub>g</sub>, and the report names the method in its heading, prints the `C1 = fn(M1, M2, Mo, psi, mu)` line in standard mode and the ratio M<sub>cr,eigen</sub>/M<sub>cr,standard</sub> in eigen mode.

**MasterSeries-format design brief (EC3):** for `S.code === 'EC3'` the report is the verdict banner followed by the brief rendered by `renderMasterSeriesBrief(a, c, sec)` in `js/06-brief-masterseries.js` (one brief, nothing else, since 20 Sep 2026) &mdash; a pure function of the analysis result, the check result and the section (no DOM) that prints the checks in the order, wording and three-column layout of a MasterSeries "MasterSteel Beam Design to EN 1993-1-1" printout (label | formula with substituted values | result + tag), as specified line by line in [docs/BRIEF_MAPPING.md](docs/BRIEF_MAPPING.md). Variants: Beam &amp; Beam-Portion (no axial force, M<sub>z</sub> = 0) and Axial with Moments; fully restrained (`M<sub>b.Rd</sub> = M<sub>c.y.Rd</sub>  Fully Restrained`), closed section ("not susceptible to LTB"), cantilever (SN006a chain in standard mode), channel (&kappa; chain), and both `S.mcrMethod` routes (FE eigenvalue lines, or `C<sub>1</sub> = fn(M<sub>1</sub>, M<sub>2</sub>, M<sub>o</sub>, &psi;, &mu;)` / `M<sub>cr</sub> = Fn(C<sub>1</sub>, L<sub>e</sub>, I<sub>z</sub>, I<sub>t</sub>, I<sub>w</sub>, E)` in standard mode). Every number printed is a field of the check object (V<sub>pl.z.Rd</sub>, A<sub>v,z</sub> and M<sub>c.z.Rd</sub> come from the engine's `c.ax` block) or is derived by one of the small pure `msb*` helpers (N<sub>Rk</sub>, M<sub>y.Rk</sub>, k<sub>c</sub>, &psi;, &mu;, unity-bar maximum) with the formula shown; no resistance is recomputed. Blocking messages (`c.unsupported`) appear as red `NOT VERIFIED` rows in the block of the check they concern (a message no block claims is printed before the deflection block) and again in the footer, the title carries `(FAIL)` or `(NOT VERIFIED)`, ratios above 1 carry a red `Warning` tag, a failing brief has the light-blue MasterSeries panel, and the unity bar ends with `Max` (deflection excluded). `tests/brief.test.cjs` renders the demo beam, a UB with axial compression and M<sub>z</sub>, a PFC with an eccentric load, a cantilever, an SHS, a single span with two intermediate lateral restraints (three bays), a Class 4 case, and the six end presets plus a custom guided case, in both M<sub>cr</sub> methods and checks the block order, the End conditions line, the reaction cells per end type, the unity-bar `Max`, the printed M<sub>c.y.Rd</sub> and M<sub>y.Ed</sub>/M<sub>b.Rd</sub> values against `c.McRd` / `c.ltbUtil`, and that every blocking message is printed.

**Uplift, strut lengths and the deflection limit (19 Sep 2026 gap closure, group G1, restated for the single-span scope; AUDIT.md "19 Sep 2026 gap closure" and "19 Sep 2026 scope change"):**

- *Automatic pattern loading* left with the multi-span scope: `comboLoadPieces(combo)` is the plain per-load list every consumer reads; the only generated combinations are the &gamma;<sub>G,inf</sub> companions below.
- *Uplift / hold-down*: every ULS and SLS combination's end reactions are tested, the &gamma;<sub>G,inf</sub> companions (G at 1.0 and 0.9) included; an end lifting in a ULS combination prints "Hold-down required: R = &minus;x kN at End n (combination &hellip;)" and blocks PASS unless that end's "hold-down provided" box is ticked (advisory with the design force); an end lifting only in SLS combinations (a deflection case is not a ULS equilibrium state; needs a user SLS combination without G since the 20 Sep 2026 default 1.0G + 1.0Q) is an advisory that names the force. A guided end (R<sub>y</sub> held, U<sub>z</sub> free) has no vertical reaction. Member Forces block of the brief; reactions line of the report; BS 5950 path included.
- *Strut lengths* (`lcrDefaults(S)`): from the end fixities &mdash; y-y from U<sub>z</sub> / R<sub>y</sub>, z-z from U<sub>y</sub> / R<sub>z</sub>: 0.7 L (held in position and direction at both ends), 0.85 L (direction at one end), 1.0 L (direction at neither), 2.0 L (cantilever: one end held in position and direction, the other free), 1.2 L (fixed end with a guided / sway-permitted far end), 2.0 L theoretical (pinned end with a guided far end), mechanism otherwise; printed with the basis and [verify]; the entered L<sub>E</sub>/L overrides both axes; the minor axis is still capped by the lateral-restraint spacing (P360 6.2).
- *Deflection*: span/`S.divisor` between two vertically held ends, L/`S.divisorCant` (default 180, UK NA Table NA.2 cantilever row [verify]) when an end is vertically free (cantilever tip, guided tip: the tip deflection relative to the held end), both capped by the optional absolute limit `S.deflAbs` (mm). The brief and the report print the limit used.

Regression tests: `tests/gap-closure.test.cjs` (statics, the strut table, the deflection limit), `tests/structural.test.cjs` (guided end wL&sup2;/3 and wL&sup2;/6, presets, `lcrDefaults`, validation messages, laterally clamped LTB against the SN003a k = 0.5 factor), `tests/ui-state.test.cjs` (the End conditions panel state: presets set the flags and keep the seating entries, a flag change sets the selection to custom, the panel / glyph string builders, the End conditions line, the end-moment sign at both ends). Run the batch campaign with `node tests/batch/run-batch.cjs` (see tests/batch/README.md).

**Web transverse forces, EN 1993-1-5 clause 6 with the 7.2 interaction (19 Sep 2026 gap closure, group G2; AUDIT.md "19 Sep 2026 gap closure, group G2"):** on the EC3 path (fully restrained and both unrestrained routes) `webTransverseCheck(a, sec, fy, eps, cl)` in `js/checks/eurocode-checks.js` checks every point load and every support reaction as a patch load on the web: load types (a) interior, (b) through the web (a point load directly over a support, F<sub>Ed</sub> = max(P, R)) and (c) near an unstiffened end (evaluated together with (a) whenever s<sub>s</sub> + c &lt; 2h<sub>w</sub>/3, the lower F<sub>Rd</sub> governing); k<sub>F</sub> per Figure 6.1, F<sub>cr</sub> = 0.9k<sub>F</sub>Et<sub>w</sub>&sup3;/h<sub>w</sub>, m<sub>1</sub>, m<sub>2</sub> (one re-evaluation with m<sub>2</sub> = 0 when &lambda;&#772;<sub>F</sub> &le; 0.5), l<sub>y</sub> per 6.5(3)/(4), &chi;<sub>F</sub> = 0.5/&lambda;&#772;<sub>F</sub> &le; 1, F<sub>Rd</sub> = f<sub>yw</sub>L<sub>eff</sub>t<sub>w</sub>/&gamma;<sub>M1</sub>; &eta;<sub>2</sub> + 0.8&eta;<sub>1</sub> &le; 1.4 with &eta;<sub>1</sub> = M<sub>Ed</sub>/M<sub>c,Rd</sub> (+ N<sub>Ed</sub>/N<sub>pl,Rd</sub>) at the same station of the same ULS combination. Inputs: per point load `ld.ss` (stiff bearing length, mm, blank = 0) and `ld.stiff`; per end `S.ends.e1.ss` / `e2.ss` (blank = the lower bound 0 since the review fixes: a station failing at 0 is NOT VERIFIED until the seating length is entered) and `.stiff` ("bearing stiffener provided": the station prints "stiffener declared - design stiffener separately (EN 1993-1-5 9.4)" as an advisory instead of the check and bounds the panel length a of the other stations; without any declared stiffener a = L, printed). Sections: rolled I/H, PFC (one-sided flange), RHS/SHS (two webs of thickness t with the tabulated flat depth, flange share B/2 per web, load shared by the lever rule of its eccentricity). Verdict entries `Web transverse force  F_Ed/F_Rd (EN 1993-1-5 6.2)` and `Web transverse force + bending (EN 1993-1-5 7.2)` (worst station each; a failing station is a FAIL with a "Bearing stiffener required" advisory). Brief: block "Web Transverse Forces (EN 1993-1-5 cl 6)" directly after Local Capacity (geometry, m<sub>1</sub>/m<sub>2</sub>, a, the governing station's full chain, one table row per station, unity cells `F/F_Rd` and `Web 7.2`); report: block after Moment Resistance with the same content. Regression tests `tests/web-transverse.test.cjs` (hand-derived values, see AUDIT.md); batch cross-checks (viii-FRd, viii-Mend: the end stations read M<sub>Ed</sub> a fraction inside the member, so a fixed / guided End 2 carries its hogging moment - review finding F-A). Not evaluated (printed): distributed loads as patch loads, hanger loads, the closely spaced total-load check (6.3(3)), flange-induced buckling (section 8), the stiffener itself (9.4); the BS 5950 path keeps its cl 4.5 advisory.

**Classification, effective area, M-V-N, k<sub>c</sub> floor, RHS k<sub>ij</sub>, channel torsional buckling, high-shear M<sub>v,Rd</sub> for every family, restraint forces (19 Sep 2026 gap closure, group G3; AUDIT.md "19 Sep 2026 gap closure, group G3"):**

- *Minor-axis classification of I/H* (`classifyEC3`, `mzFlangeStress`): an applied M<sub>z</sub> does not stress the web of an I/H section, so the web keeps its y-y bending (+N) limits and the flanges are classified as outstands under the combined stress (the outstand compressed by M<sub>z</sub> is wholly in compression, &alpha; = 1, so the 9&epsilon;/10&epsilon;/14&epsilon; bound governs; the stresses are printed). Channels and hollow sections keep the conservative uniform-compression bound. A UB with M<sub>z</sub> is now evaluated (Class 1/2 when its geometry is) instead of NOT VERIFIED.
- *A<sub>eff</sub> of a Class-4 web in uniform compression* (`aeffWebCompression`, EN 1993-1-5 4.4, &psi; = 1, k<sub>&sigma;</sub> = 4, &rho; = (&lambda;&#772;<sub>p</sub> &minus; 0.22)/&lambda;&#772;<sub>p</sub>&sup2;, b<sub>eff</sub> split 0.5/0.5): used in N<sub>c,Rd</sub>, in N<sub>b,Rd</sub> (&lambda;&#772; = &radic;(A<sub>eff</sub>f<sub>y</sub>/N<sub>cr</sub>)) and in Eq 6.61/6.62 with the Table 6.7 Class-4 column (N<sub>Rk</sub> = A<sub>eff</sub>f<sub>y</sub>, W<sub>eff,y</sub> = W<sub>el,y</sub> when the flanges stay Class &le; 3, assumption printed). The former "web Class 4 in uniform compression" block is gone; a 1016&times;305&times;249 with N = 3000 kN evaluates with A<sub>eff</sub> = 0.905A. Class 4 under the combined stress gradient and Class-4 flanges still block.
- *cl 6.2.10* (`shearReducedResistances` + the station sweep, `c.mvn`): at every ULS station with V<sub>Ed</sub> &gt; 0.5V<sub>pl(,T),Rd</sub> and N<sub>Ed</sub> &ne; 0 or M<sub>z</sub> &ne; 0 the shear area takes (1 &minus; &rho;)f<sub>y</sub>: N<sub>V,Rd</sub>, M<sub>v,y,Rd</sub>, M<sub>v,z,Rd</sub>, a<sub>V</sub>, then the 6.2.9.1 chain (M<sub>N,V,Rd</sub> with the (4) waiver, Eq 6.39/6.40 for RHS, linear for Class 3 and channels); uniaxial = plain ratio, biaxial with the &alpha;/&beta; exponents. Verdict entry "Bending+shear+axial (6.2.10)", brief row after the coexistent M-V row, unity cell "M-V-N".
- *High-shear M<sub>v,Rd</sub> for every family*: I/H Class 3 (W<sub>el,y</sub> &minus; &rho;I<sub>web</sub>/(h/2))f<sub>y</sub> [conservative], channels (W<sub>y</sub> &minus; &rho;t<sub>w</sub>h<sub>w</sub>&sup2;/4)f<sub>y</sub>, RHS/SHS (W<sub>y</sub> &minus; &rho;t(h &minus; 2t)&sup2;/2)f<sub>y</sub>; the I/H Class 1/2 form is unchanged. Applied at the peak-moment station (`c.McRd`, `c.mvForm`) and in the span-wise sweep (`c.coex`); the family/class blocks are gone.

Mapping: e = x<sub>w,load</sub> &minus; x<sub>w,sc</sub> (beam-v03's own sign, + inward), z<sub>g</sub> from the height choice (top flange default in every ledger; the 'plate' choice follows the plate side and is withdrawn - rows normalised to the flange - when the plate is switched off), `S.eccOn` true whenever any e or z<sub>g</sub> is non-zero or the section is a channel (its automatic self-weight is eccentric and beam-v03 adds that torque only on its eccentric path), `S.za` (beam-v03's default z<sub>g</sub>) held at 0 and hidden, moments carry no e / z<sub>g</sub>, self-weight stays automatic. A span change re-syncs the ledgers (`wallClampRowsToSpan()`, the same rules as `clampLoadsToSpan()`), never the other way round; Reset restores the demo wall.
