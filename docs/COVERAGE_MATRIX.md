## 0. How to read this matrix

**EC3 code path.** `checks()` (`js/04-checks.js:307-308`) sends a fully restrained beam to `checksEC3Restrained` (`js/checks/eurocode-checks.js:270-582`) and an unrestrained beam to `window.checksEC3UnrestrainedSCI`, which `js/08-mcr-eigen-patch.js:463` reassigns to the FE eigenvalue version (`08:463-813`). The unrestrained version calls the restrained one first (`08:464`), so every cross-section, torsion, axial and deflection check below is shared; only LTB, Annex A and the `Mb,Rd` fed into 6.61/6.62 differ. The original closed-form LTB chain (`sn003aC1` `eurocode-checks.js:584-611`, `checksEC3UnrestrainedSCI` `613-874` with SN003a/C2, SN006a cantilever tables, PFC kappa chain and the P362 Expn 6.55 route; helpers `computeC1`, `mcrEC3`, `ltbCurveEC3`, `SN006`, `sernaC1` in `js/01-computation-engine.js:264-393`) is present but unreachable on the EC3 path.

**Verdict logic.** `pass = unsupported.length === 0 && every util <= 1.0001` (`eurocode-checks.js:578`, `08:808`). The report prints PASS / FAIL / NOT VERIFIED (`js/06-render.js:68`); `unsupported[]` entries render as "NOT COVERED" and block PASS, `advisory[]` entries render as "ADVISORY (does not block PASS)" (`06:100-101`).

**Status vocabulary** (from the trigger list): IMPLEMENTED = computed and in the verdict; BLOCKING = detected, PASS refused with a NOT VERIFIED message; ADVISORY = noted, not in the verdict; MISSING = trigger not detected at all; N/A = cannot occur in this tool.

**Priority.** P1 = a beam with the loads in scope would get a wrong PASS without it; P2 = incomplete verification (NOT VERIFIED where a PASS/FAIL could be established, or a conservative/inconsistent value); P3 = out of scope for a rolled-section beam tool. Effort S/M/L.

**Loads in scope.** Point, UDL, trapezoidal/UVL, applied moments, internal hinges, pinned/fixed supports, multi-span, cantilever, eccentricity e (torque), load height zg, axial N, minor moment Mz; sections UB/UC/PFC/SHS/RHS. Inputs: `js/03-state-ui.js:9-24` (DEMO), `index.html:87-165`.
