# beam-v03 vs MasterSeries 2025.20.11 — live comparison (20 Sep 2026)

Fourteen single-member models were written as MasterFrame text files (`models/*.$5`, generated by script — node coordinates, member loads, section number, Eurocode load cases and the EC3 design-code flag are all plain text), opened in MasterFrame, analysed as a space frame and designed in MasterKey Steel (Sections module, EN 1993-1-1 + UK NA). Every line of every printout was read from the screen and transcribed in [COMPARISON_LOG.md](COMPARISON_LOG.md) next to the beam-v03 run of the same input (`run-case.cjs <CASE> [standard|eigen|both]`, plus one-off harness runs quoted in the log). Full 9 m "first generation" runs (UB-L1, UB-L2, PFC-L2) are in the log too; the table below is the sized "second generation" set.

Common basis: S275, fork ends (MasterFrame node 1 dX dY dZ Rx, node 2 dY dZ Rx), ULS 1.35 G + 1.5 Q, SLS 1.0 G + 1.0 Q, self-weight automatic (at the shear centre in MasterSeries; for the PFC torsion case it is switched off with `UT D 000.000` and re-applied at the centroid). e = horizontal offset of the load line from the shear centre.

## What MasterSeries does (observed)

1. **Mcr** is always the doubly-symmetric closed form `Fn(C1, Le, Iz, It, Iw, E)` — for UB, UC and PFC alike, with or without torsion, and with a full-span Le; C1 comes from a table keyed on (M1, M2, Mo, psi, mu) and stays at the UDL value 1.127 for any single-span diagram whose mu saturates at 300 (UDL + point load, UDL + applied moment). Warping-fixed ends do not change Mcr (kw = 1).
2. **Cantilevers**: only when the brief is switched to "Cantilever - Warping Free/Fixed" and only for I sections does it use the NCCI SN006a coefficients (C = 2.029 / 4.665 for the UB, identical to beam-v03). A **channel cantilever** keeps the beam C1 table (C1 = 2.135 from the root and tip moments) whatever the warping setting — Mcr 697 vs 459 (FE, warping-free root): **Mb.Rd 20 % high**. Left at "Non-Cantilever" it prints a one-line caution and designs the cantilever as a beam segment (C1 = 1.75) with a chord-relative "in-span" deflection of 1 mm.
3. **chi_LT,mod** with kc = 1/sqrt(C1) and the f-factor is applied everywhere, including cantilevers (f = 0.853 → Mb.Rd +17 %) and restrained bays; the UK-NA rolled-section curve (lambda_LT,0 = 0.4, beta = 0.75) is used for open sections, curve d for the PFC.
4. **Cross-section interaction** exponents: alpha = 2, beta = 1 (I/H), 1.66 (hollow), **1 for channels** (6.2.9.1(6)); the hollow-section version is repeated with a torsion-reduced Mpl (Smod).
5. **Torsion**: SCI P385 method — Mzt = My·theta, Mw = E·Iw·theta''·(h−tf)/2, k = kw·kzw·ka amplifier (EN 1993-6 Annex A form) evaluated at "torsion stations", tau_tw = G·t·theta' with the web-shear factor Smod; theta is the elastic value even when it is 1.45 rad; when My.Ed > Mcr the amplifier k goes negative and its (negative) product is still added; 2-degree SLS twist limit reported in the deflection column (worse of delta/limit and theta/2 deg).
6. **Axial + bending**: the section is classified under the actual N + M (Class 1 here) → gross A, W_pl, Table B.2 class 1/2 k-factors; a torsional-buckling strut resistance Nb.T is printed for I sections; kzy = 1 − 0.1·lambda_z·nz/(CmLT − 0.25) without the Table B.2 floor; Cm from Table B.3 (0.95 for the UDL row, 0.6 for a linear diagram).
7. **Load height**: no input — `Torq ey` on a vertical load is ignored; the user picks Le = 1.2 L (the BS 5950 destabilising convention) from the Le list.
8. **Intermediate restraints**: portions between restraint points designed separately, each with its own C1 and CmLT (alpha_s form) — a "Bottom flange restrained" point in a sagging span is still counted as a full restraint (an Annex-G-style "a (mm)" box appears but is not evaluated at a = 0).
9. **Biaxial**: minor-axis loads (UDLZ, PZ) give Mz, Vz, Mc.z, Cmz from Table B.3 and a **resultant** deflection against L/360; the cantilever tip is also checked against L/360.

## beam-v03 findings from this exercise (to act on)

- **F-G** the eigen route silently ignores the L_E override (`leFactor`); the standard route applies it. Either apply it to the FE model or print that it is not used.
- **F-H** the standard route ignores intermediate LTB restraints (treats the member as one segment); the segment with its own C1 should be used, as MasterSeries does. The eigen route's bay-isolation check works (C1 inputs identical to MasterSeries) but uses chi without the f-factor (7 % low).
- **F-I** channel cross-section check: beam-v03's P385 3.1.2 squares My/Mpl; EN 1993-1-1 6.2.9.1(6) gives exponent 1 for a channel (MasterSeries) — beam-v03 is unconservative here (0.366 vs 0.566 on PFC46-L2).
- **F-J** no minor-axis loads, minor-axis shear, or resultant deflection (only a constant M_z,Ed) — MasterSeries fails UB6-L5 on the resultant deflection, beam-v03 passes it.
- **F-K** axial + bending on a UB whose web is Class 4 in uniform compression: beam-v03 switches the whole 6.61/6.62 check to A_eff, W_el and the Class 3/4 k-factors (15 % more conservative than MasterSeries' N + M classification); Cm = 1.0 for mixed diagrams (MasterSeries 0.95).
- **F-L** the 2-degree SLS twist is an advisory in beam-v03 and a FAIL column in MasterSeries; decide which convention to follow.
- **F-M** the channel kappa chain (standard route) is 2–4.5x more conservative than the Mcr route at high slenderness (PFC46-L2: Mb 49.5 vs 90.4 / 93.8); the eigen route should be the default for channels with torsion.
- Cantilever f-factor (f = 1 in beam-v03) and the L/180 vs L/360 tip limit are deliberate and documented; the channel-cantilever Mcr is where MasterSeries is unconservative, not beam-v03.

## Files

- `models/MS*.$5` — the MasterFrame inputs (the L1/L2 9 m first-generation files, the sized second-generation files, the three cantilever files). Records: `D1 UDLY`, `L1 PY`, `L1 PX` (axial), `L1 UDLZ` / `L1 PZ` (horizontal), `L1 PMZ` (point moment), `UT Torq ex ey` (eccentricity for the loads that follow), `UT D 000.000` (self-weight off); `SEC +nnnn` = library number (UB 82 +0031, UC 60 +0098, PFC 23 +5030, PFC 46 +5023, SHS +2058, RHS +2157); Data Set 112 = 2 selects the Eurocode; the two comma lines after the restraints are the load cases (field 3 = D1, field 13 = L1 factors).
- `run-case.cjs` — beam-v03 runner for the named cases; `run-l2.cjs` — the UB-L2 torsion dump used for the first entry.
- `COMPARISON_LOG.md` — the transcribed printouts and the beam-v03 numbers, case by case.
